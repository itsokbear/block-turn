# Block Turn

Мобильная блоковая головоломка/PWA: https://itsokbear.github.io/block-turn/

## Правила

- Поле 8×8, три фигуры. Тап вращает на 90°, перенос устанавливает; заполненные строки и столбцы очищаются одновременно.
- 14 форм с зеркальными вариантами. Веса: обычные 70, S/Z 35, три клетки 14, две 10, одна 7. Новая тройка гарантирует хотя бы один ход с учётом вращения, если на поле есть место.
- Очки: 10 за клетку + 100 за линию × комбо. Ход без очистки сбрасывает комбо.
- Бомба 3×3 выдаётся на комбо 4, 8, 12… Полная очистка **фигурой** даёт золотую бомбу 5×5. Хранится одна бомба, на старте нет. Взрыв не меняет комбо, фигуры и реролл.
- Реролл выдаётся за **3+ линии** одной фигурой. Хранится один, на старте нет. Заменяет выбранную оставшуюся фигуру на размещаемую, по возможности другого класса с точностью до вращения. Не меняет очки и комбо.
- Конец игры: фигуры не помещаются даже после вращения, нет бомбы и реролла.
- При переносе красная рамка предупреждает о тупике после хода; янтарная — о необходимости бонуса. Последняя фигура тройки не оценивается. Перед итоговой табличкой поле рассыпается.

## Оформление

Постоянные названия: 2 параллельные линии — **ОТЛИЧНО!**, строка + столбец — **В ТОЧКУ!**, 3 — **БЛЕСТЯЩЕ!**, 4 — **МАСТЕРСКИ!**, 5+ — **ГЕНИАЛЬНО!**, полная очистка фигурой — **БЕЗУПРЕЧНО!**. Один ход — одно событие и один звук; награды во второй строке. Эффекты учитывают reduced motion.

Classic / Neon Glow переключаются кнопкой палитры. Звук включается отдельно. На телефоне относительный перенос ×1,5; возврат фигуры за нижний край отменяет действие. Поворот 70 мс не блокирует следующие тапы.

## Запуск и проверки — только Docker

```sh
docker compose up -d --build
# http://localhost:8088
docker run --rm -v "$PWD:/app" -w /app node:lts-alpine sh -c 'npm ci --no-audit --no-fund && npm test && npm run typecheck'
docker build --target build --build-arg NEXT_PUBLIC_BASE_PATH=/block-turn -t local/block-turn:pages-build .
```

GitHub Actions публикует `main` в GitHub Pages. Проверка экспортированных HTML и офлайн-ресурсов входит в Docker build.

## Сохранения и PWA

localStorage: `block-turn-game`, `block-turn-best`, `block-turn-skin`. Старые партии мигрируют без сброса. Разные адреса имеют отдельные сохранения.

На iPhone: Safari → Поделиться → На экран Домой. После сообщения о готовности игра работает офлайн. Обновления проверяются при возврате, восстановлении сети и каждую минуту; применяются кнопкой с сохранением партии.

Локальные `releases/` содержат архив исходного релиза; `.deploy/` — средства SSH-деплоя. Они исключены из Git и Docker-контекста. Карта кода и правила изменений — в `AGENTS.md`.
