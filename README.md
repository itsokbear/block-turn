# Block Turn

Мобильная веб-игра с полем 8×8. Нажатие на фигуру в зоне ожидания поворачивает её на 90°. Перетаскивание устанавливает фигуру; можно также выбрать фигуру и нажать клетку её верхнего левого угла. Заполненные строки и столбцы очищаются одновременно. Конец игры учитывает все четыре ориентации оставшихся фигур.

## Запуск в Docker

```sh
docker compose up -d --build
```

Игра: http://localhost:8088. На телефоне в той же Wi-Fi сети: `http://<LAN-IP компьютера>:8088` (если входящие подключения разрешены). Отдельный контейнер `block-turn`, порт 8088. Никакие Node.js/npm на компьютере не нужны. Сборка внутри Docker, готовые файлы раздаёт nginx.

```sh
docker compose down
docker compose logs --tail=50
docker run --rm -v "$PWD:/app" -w /app node:lts-alpine node --experimental-strip-types --test tests/game.test.ts
```

Партия и рекорд сохраняются в localStorage текущего браузера. Без сервера аккаунтов; разные браузеры и адреса имеют отдельные сохранения. Звук включается кнопкой. Счёт: 10 за клетку, 100 за линию с множителем последовательных ходов с очисткой.

## Новые механики

- Квадрат 3×3 входит в случайный набор фигур.
- На старте бомбы нет; каждый третий подряд ход с очисткой линий даёт одну бомбу (3, 6, 9…), если она ещё не доступна. Максимум одна бомба. Ход без очистки обнуляет серию. Старые запасы ограничиваются одной бомбой без сброса партии. Кнопка серая без бомбы и подсвечена при её наличии.
- Бомбу можно перетащить или выбрать и нажать клетку. Очищается полный квадрат 3×3 вокруг выбранной клетки; на краях область сдвигается внутрь поля. Бомба не меняет серию комбо и не расходует фигуры. Пока есть бомбы, партия не заканчивается.
- При переносе фигуры подсвечиваются строки и столбцы, которые очистятся. Для бомбы подсвечивается область взрыва.
- На сенсорном экране перенос работает как относительный тачпад с коэффициентом 1,5: фигура входит в поле снизу над собственной зоной ожидания, без прыжка в центр. Возврат фигуры за нижний край отменяет перенос без сообщения. Кнопка бомбы расположена между счётом и рекордом и входит в поле сверху. Мышью можно вернуть фигуру в зону ожидания.

Проверено 24 автоматическими тестами логики и TypeScript. Ручная проверка жестов на физическом телефоне не выполнялась.

Полная очистка после установки фигуры или взрыва запускает волну света, искры и «Чистая работа!» (1,2 с, без блокировки ввода), а при включённом звуке — аккорд. Только полная очистка установкой фигуры выдаёт одну золотую бомбу 5×5, заменяющую обычную. Очистка взрывом празднуется, но новую бомбу не выдаёт. Уже пустое поле награды не даёт. Золотой статус сохраняется с партией; предпросмотр учитывает 5×5. Обычные уведомления об очках — полупрозрачные, без рамки, у верхнего края поля; видимы 0,65 с.

## Релизы и сложность

Исходная версия 1.0.0 сохранена в `releases/` вместе с исходниками, автономным образом Docker и инструкцией возврата. Текущая вариация возвращает маленькие фигуры с пониженной вероятностью: каждая фигура из 3 клеток имеет вес 1/5 от основной, из 2 — 1/7, из 1 — 1/10. Основные фигуры (4+ клеток) равновероятны между собой. Веса целые: 70, 14, 10, 7; каждое место набора выбирается независимо. Из трёхклеточных возвращены линия и уголок. Уже выданные фигуры сохранённой партии остаются; новые наборы используют взвешенную выдачу.

В выдаче 14 типов фигур, включая обе зеркальные версии четырёхклеточного уголка (L/J) и зигзага (S/Z). У остальных отражение совпадает с одним из поворотов, поэтому дубликаты не добавлены. Каждый зеркальный вариант получает обычный вес для своего числа клеток.

## PWA и GitHub Pages

PWA сохраняет все файлы проверенной сборки в отдельный версионированный кэш. Стартовая страница и ресурсы работают офлайн после сообщения «Готово к игре без интернета». Неполная загрузка не заменяет рабочий кэш. Обновление применяется по кнопке, сохранённая партия остаётся в localStorage.

На iPhone: открыть HTTPS-адрес в Safari → «Поделиться» → «На экран Домой» → открыть игру с новой иконки при включённой сети → дождаться готовности офлайн-режима. После этого можно отключить сеть и компьютер. Данные на новом адресе отдельные от localhost/LAN; очистка данных сайта в iOS удалит офлайн-кэш и сохранение.

GitHub Pages: `.github/workflows/pages.yml` собирает игру внутри Docker и публикует `dist/client`. В Settings → Pages нужно выбрать Source: GitHub Actions. Для репозитория `itsokbear/block-turn` адрес — `https://itsokbear.github.io/block-turn/`. Docker локально продолжает использовать `/` и порт 8088. По HTTP LAN офлайн-установка недоступна; HTTPS GitHub Pages устраняет это ограничение.

```sh
docker run --rm -v "$PWD:/app" -w /app node:lts-alpine node --test tests/pwa.test.mjs
docker build --target build --build-arg NEXT_PUBLIC_BASE_PATH=/block-turn -t local/block-turn:pages-build .
```

Дополнительно проверяются работа service worker без сети, поведение при неполной загрузке, применение обновления и пути каждого ресурса в экспортированной игре. Проверка на физическом iPhone проводится после публикации.
