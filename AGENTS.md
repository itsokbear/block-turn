# BlockTurn — вход для нового диалога

Это самостоятельная игра. История предыдущих диалогов не нужна.
Сначала прочитай этот файл и `README.md`, затем только файлы по задаче.
Правила и сохранения — `docs/RULES.md`; читай при изменениях механик.

## Работа

- Все Node/npm, проверки и сборки — только в Docker. `./scripts/check.sh` запускает тесты и TypeScript в чистом образе; зависимости на хосте не нужны.
- Локальная игра: `docker compose up -d --build`, http://localhost:8088. Compose-проект имеет постоянное имя `block-turn`.
- Публикация: `main` → GitHub Actions → https://itsokbear.github.io/block-turn/. Проверить Pages-сборку командой из README, затем коммит и `./scripts/publish.sh`. После push дождаться успешного Actions для своего SHA.
- Менять только запрошенное; не трогать баланс, жесты и сохранения ради визуальных правок. Добавлять осмысленные тесты для изменённой логики.
- Локальные `.deploy/` и `.local/` исключены из Git и Docker. Не читать/печатать приватный ключ и не добавлять эти каталоги в коммиты. Референсы дизайна — `.local/design/`, исторический релиз — `.local/releases/`.
- Проверять визуальные правки в графическом браузере на мобильной ширине. Не заявлять проверку на физическом iPhone без неё.

## Не нарушать

- Реролл за 3+ линии, бомба за каждое 4-е комбо; максимум по одному, на старте нет.
- Serpent неуязвим. Скорлупка = значение `6` / внутреннее имя `POOP`; `won` оставлен для миграции старых сохранений, победу не возвращать.
- Тап мгновенно вращает фигуру; анимация не блокирует быстрые тапы. Подавлять iOS selection/callout.
- Один placement — один итоговый звук/overlay. Полная очистка фигурой имеет высший приоритет; взрыв не выдаёт награды.
- Имена localStorage-ключей не менять. Pages base path `/block-turn`, локально пустой; manifest, SW и офлайн-ресурсы должны сохранять правильную область действия.
