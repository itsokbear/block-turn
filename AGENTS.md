# Block Turn: краткий контекст для изменений

## Workflow
- Это существующая игра, не создавать новый проект/хостинг. GitHub Pages: https://itsokbear.github.io/block-turn/; remote `origin`, ветка `main`.
- Все Node/npm, проверки и сборки выполнять в Docker. Локальный контейнер — `docker compose up -d --build`, порт 8088.
- Перед правками читать только относящиеся к задаче файлы. Актуальные правила — README; история разговора не нужна.
- Не менять баланс, жесты, сохранения или оформление вне запрошенной задачи.
- Не трогать локальные `.deploy/`, `releases/`, `.openai/`, `output/`; не добавлять их в Git/образ. Не выводить приватный ключ.
- После публикации проверить успешное завершение GitHub Actions. Не заявлять проверку на физическом iPhone без её проведения.

## Карта
- `lib/game.ts`: чистые правила, веса, сохранения, бомбы, реролл, риск хода. Баланс: `REROLL_LINES_THRESHOLD=3`, `BOMB_COMBO_THRESHOLD=4`.
- `lib/events.ts`: классификация и единственный `MOVE_EVENT_COPY`; награды определяются сравнением состояний.
- `lib/drag.ts`: относительные мобильные жесты; `lib/audio.ts`: синтез звука.
- `app/page.tsx`: взаимодействие и UI; `app/globals.css`: Classic/Neon, адаптивность, анимации.
- `app/pwa-status.tsx`, `lib/pwa-updates.ts`: регистрация и поиск обновлений.
- `scripts/sw-template.js`, `build-pwa.mjs`, `verify-pwa.mjs`: атомарный офлайн-кэш и экспорт с base path.
- `tests/`: правила, события, риск, жесты, звук, PWA и миграции.

## Инварианты
- Партия/рекорд/скин сохраняются под прежними localStorage-ключами; старые партии не сбрасывать.
- Бомба и реролл максимум по одному. Взрыв не даёт наград и не расходует реролл.
- Новая тройка и реролл используют существующие веса и проверяют все повороты.
- Полная очистка фигурой имеет высший приоритет события. Взрыв не создаёт move classification.
- Каждый placement — один звук/overlay. Тапы вращения не блокировать; native selection/callout iOS подавлять.
- `NEXT_PUBLIC_BASE_PATH=/block-turn` для Pages, `/` локально. Не ломать manifest, SW scope и URL.

## Проверки
- `npm test` и `npm run typecheck` внутри Node Docker после изменений логики.
- Docker build включает проверку PWA; для публикации также сборка с `/block-turn` (команда в README).
- Зависимости и lockfile обновлять вместе, только в Docker.
